WIN2MAC · MAC VALIDATION

一键收集 Mac 端日志

这个工具会在 Mac 上检查转换产物、尝试启动应用，并把完整日志和系统信息打包到桌面。把生成的诊断 ZIP 发回给 Windows 侧的打包者即可。

怎么用

1
解压转换产物

用 Finder 解压 Win2Mac 生成的 ZIP。不要用 Windows 资源管理器解压。

2
把本工具放到 .app 旁边

如果工具文件夹和 .app 不在同一层，直接把 .app 拖到 Start-Mac-Validation.command 上也可以。

3
双击开始验证

首次打开若被 Gatekeeper 拦截，请到“系统设置 → 隐私与安全性”点“仍要打开”；macOS 14 及更早也可右键 → 打开。

4
把桌面诊断包发回

验证结束后 Finder 会弹出诊断 ZIP。日志全文也在桌面。

macOS 15/26：右键 → 打开通常已不可用。双击被拦截后，打开“系统设置 → 隐私与安全性”，在“安全性”下方点“仍要打开”，再双击本工具。也可以在终端进入本文件夹后运行 xattr -dr com.apple.quarantine . 和 chmod +x *.command。

日志和诊断包在哪

~/Desktop/Win2Mac-验证日志-日期-时间.log
~/Desktop/Win2Mac-诊断-日期-时间.zip

诊断 ZIP 包含：完整验证日志、macOS/机型/显卡信息、应用的 Info.plist 与配置、该应用的 Wine 启动日志。它不包含应用文件本体。

如果启动时间很长

首次启动可能下载 Wine 引擎（约 184 MB）或安装运行库，30 秒内未必完成。工具会先收集当前日志；等应用窗口出现后，再双击一次工具，就能把后续完整日志带上。

隐私提示：日志可能包含 Mac 用户名、安装路径、应用输出内容。只发送给可信的打包者，不要公开上传。Windows 应用与商标归各自权利人所有；本工具不授予分发权。
