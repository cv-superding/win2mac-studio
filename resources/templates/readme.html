第一次打开（重要）

这个包没有 Apple Developer ID 签名与公证，macOS 会拦截未签名的 .command 和 .app。这是系统安全策略，不代表文件有问题。

只需要放行一次。任选一种：

方法 A：图形界面

  1. 双击 Open-Win2Mac-App.command，在提示框点“完成”。
  2. 打开 系统设置 → 隐私与安全性，向下滚动到“安全性”，点“仍要打开”，输入 Mac 密码。
  3. 再次双击 Open-Win2Mac-App.command。它会清除整个文件夹的隔离标记、修复脚本权限并打开应用。

macOS 14 及更早版本也可以右键该 .command → 打开；macOS 15/26 上右键打开通常不可用，请用“仍要打开”。

方法 B：终端命令（最可靠）

  1. 打开“终端”（启动台搜索“终端”）。
  2. 输入 cd （后面有一个空格），把整个解压后的文件夹拖进终端窗口，回车。
  3. 运行下面三行命令：
xattr -dr com.apple.quarantine .
chmod +x *.command
open *.app

如果 .app 仍被拦截，回到“系统设置 → 隐私与安全性”点“仍要打开”。这些命令只清除本文件夹的隔离标记，不会关闭系统安全功能。

第一步：启动

  1. 把 ZIP 完整解压到“应用程序”或任意本地文件夹，不要直接在压缩包里运行。
  2. 请在 macOS 上用访达解压 ZIP。Windows 资源管理器解压会丢失 .app 与 .command 的执行权限。
  3. 按上方“第一次打开”放行一次；之后双击 Open-Win2Mac-App.command 即可启动。
  4. 首次启动会初始化 Wine 环境，可能还需要下载运行时，请保持网络连接并耐心等待。
首次启动可能需要 30 秒到数分钟。如果安装包未内置引擎，首次启动还需下载 Wine；进度与错误会写入 ~/Library/Logs/Win2Mac/{{APP_ID}}.log。
如果曾在 Windows 上解压过 ZIP，.app 与 .command 会失去执行权限。请在 Mac 上重新用访达解压，或先运行 chmod +x *.command 和 chmod +x "{{APP_PATH}}/Contents/MacOS/launcher"。

已知限制

  • Wine 不能加载 Windows 内核驱动（.sys），也不支持大多数反作弊服务。
  • Wine 无法把 USB 设备直通给 Windows 程序；依赖 ADB/手机投屏、加密狗、串口设备的应用通常不能正常工作。若打包时检测到应用自带 macOS adb，启动器会尝试本机 ADB 桥接（实验性）；失败请改用虚拟机或官方 Mac 版。
  • 依赖 DRM/激活服务、Windows 服务、IE 插件或 UWP/MSIX 的程序通常无法运行；依赖机器码的授权在 Wine 中可能失效。
  • 不保证 100% 功能与性能；游戏建议使用 Apple GPTK 或 CrossOver 的 D3DMetal。媒体播放应用可能需要在 Mac 上安装 GStreamer（缺失通常只影响音视频播放）。
  • 此安装包未使用 Apple Developer ID 签名/公证，因此需要上面的手动打开步骤。

一键诊断（推荐先运行）

双击 Start-Mac-Validation.command。它会检查系统、Rosetta、Gatekeeper、引擎、文件清单与完整性，并用详细日志模式启动 .app；结束后在桌面生成：

~/Desktop/Win2Mac-验证日志-日期-时间.log
~/Desktop/Win2Mac-诊断-日期-时间.zip

诊断包现在包含 Report.md、Report.json、Missing.txt、Repair.md、System/、Prefix/ 和 Logs/；其中 Missing.txt 会逐条列出缺失或大小不一致的文件，Report.json 可直接交给其他诊断工具/agent。

如果启动器自身失败，它也会自动在桌面生成 Win2Mac-失败诊断-*.zip，并弹窗显示路径。把任意一个诊断 ZIP 发回给打包者即可。

日志可能包含本机用户名和安装路径；只发送给可信的打包者，不要公开上传。

排障

应用闪退或没有窗口

  1. 打开日志：~/Library/Logs/Win2Mac/{{APP_ID}}.log，同时检查 launcher-*.log 和 state-{{APP_ID}}.env。每个阶段都有时间戳和返回码。
  2. 需要更详细的 Wine 输出时，在终端运行：
    WIN2MAC_DEBUG=1 "这里替换为YourApp.app/Contents/MacOS/launcher" --debug
  3. 如果诊断包里的 Missing.txt 非空，先用 Finder 重新解压原始 ZIP；仍缺失说明传输/解压不完整，请让打包者重新发送或重建。
  4. 双击 Reset-Runtime.command 重置运行环境后重试（会删除该应用的 Wine 数据）。
  5. 在 Mac 上安装 CrossOver 24+ 或 Apple Game Porting Toolkit 2，然后重新打开；启动器会自动优先复用它们。如果安装包被设为“仅复用引擎”，必须这样做。
  6. 仍无法运行时，可考虑 UTM/Parallels 运行 Windows 虚拟机，或寻找官方 Mac 版。
如果应用带反作弊、内核驱动或 DRM，请勿在 Wine 中尝试绕过；这通常违反服务条款，也可能导致账号风险。

卸载

把 .app 与同目录的说明文件移到废纸篓，然后删除 Wine 数据目录：

rm -rf "{{PREFIX_PATH}}"

此操作仅影响本机 Wine 环境，不会修改原 Windows 电脑上的任何文件。
