第一步：启动

  1. 把 ZIP 完整解压到“应用程序”或任意本地文件夹，不要直接在压缩包里运行。
  2. 请在 macOS 上用访达解压 ZIP。Windows 资源管理器解压会丢失 .app 与 .command 的执行权限。
  3. 双击 Open-Win2Mac-App.command。它会移除隔离标记、修复执行权限并打开 .app。
  4. 如果 macOS 提示“无法验证开发者”：macOS 14 及更早版本可右键该 .command → 打开；macOS 15/26 请到“系统设置 → 隐私与安全性”点“仍要打开”。
  5. 首次启动会初始化 Wine 环境，可能还需要下载运行时，请保持网络连接并耐心等待。
首次启动可能需要 30 秒到数分钟。如果安装包未内置引擎，首次启动还需下载 Wine；进度与错误会写入 ~/Library/Logs/Win2Mac/{{APP_ID}}.log。
如果 .command 无法双击，或你曾在 Windows 上解压过 ZIP：

chmod +x Open-Win2Mac-App.command
bash Open-Win2Mac-App.command

或手动：
xattr -dr com.apple.quarantine "{{APP_PATH}}"
chmod +x "{{APP_PATH}}/Contents/MacOS/launcher"
open "{{APP_PATH}}"

一键诊断（推荐先运行）

双击 Start-Mac-Validation.command。它会检查系统、Rosetta、Gatekeeper、引擎、完整性，并尝试启动 .app；结束后在桌面生成：

~/Desktop/Win2Mac-验证日志-日期-时间.log
~/Desktop/Win2Mac-诊断-日期-时间.zip

把桌面上的 Win2Mac-诊断-*.zip 发回给打包者即可。诊断包包含完整日志、系统信息和该应用的 Wine 日志，不包含应用文件本身。

日志可能包含本机用户名和安装路径；只发送给可信的打包者，不要公开上传。

排障

应用闪退或没有窗口

  1. 打开日志：~/Library/Logs/Win2Mac/{{APP_ID}}.log，查看最后的错误。
  2. 双击 Reset-Runtime.command 重置运行环境后重试（会删除该应用的 Wine 数据）。
  3. 在 Mac 上安装 CrossOver 24+ 或 Apple Game Porting Toolkit 2，然后重新打开；启动器会自动优先复用它们。如果安装包被设为“仅复用引擎”，必须这样做。
  4. 仍无法运行时，可考虑 UTM/Parallels 运行 Windows 虚拟机，或寻找官方 Mac 版。
如果应用带反作弊、内核驱动或 DRM，请勿在 Wine 中尝试绕过；这通常违反服务条款，也可能导致账号风险。

卸载

把 .app 与同目录的说明文件移到废纸篓，然后删除 Wine 数据目录：

rm -rf "{{PREFIX_PATH}}"

此操作仅影响本机 Wine 环境，不会修改原 Windows 电脑上的任何文件。
